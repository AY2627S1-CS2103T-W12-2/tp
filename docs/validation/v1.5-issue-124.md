## Confirmed defects and regression evidence

An event or role containing 80 `😀` characters was rejected because validation counted UTF-16
units. JSON loading had the same defect. The contact card also truncated a 20-emoji event
prematurely and could split the emoji after 30 ASCII characters, producing a broken preview.

Four new tests failed before the fix: `MeetingTest`, `MeetingStorageTest`, `MeetingFeatureTest`
and `PersonCardTest`. They pass after command/model/JSON validation shares a code-point bound
and card truncation uses code-point offsets. Integration coverage checks persistence, invalid
81-character updates, undo and redo. No photo defect was reproduced in the existing validation,
storage, UI and history cases, so photo behavior was preserved.
