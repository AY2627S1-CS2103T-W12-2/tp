v1.4.1 packages the fixes and UI improvements merged since v1.4, using `master` at
`17cd7588` as the release base. It does not include unmerged PR #181 or its Unicode changes.

## Changes since v1.4

- Show photos beside the name in the detail panel, in a fixed 160×120 frame that preserves
  aspect ratio. In narrow panels, move the frame below the name. Remove photos from cards.
- Show tags in stable colours and keep card tags on one row with a `+N` overflow indicator.
  Contacts with no tags show `-` in the detail panel.
- Keep active filter/order/count feedback above the list. `find`, `group`, `filter` and `due`
  retain the viewed contact when it is hidden by the results.
- Reject unsupported reserved prefixes in typed search and give clearer command usage errors,
  including when `clear` is entered before the contact index.
- List available commands for an unknown command, wrap long feedback, and remove the redundant
  `reset` command. Use `list` to restore every contact in its original order.
- Count note length using Unicode code points, so a single supplementary emoji counts once.
  This change applies to notes; meeting fields still use UTF-16 code units.
- Accept tab-separated parameters, including pasted commands. Accept quoted photo paths such
  as `photo 1 f/"my f/portrait.png"` and explain ambiguous unquoted paths.
- Reject oversized/invalid emails without recursive regex backtracking. Treat null JSON roots,
  contacts and tag entries as data errors rather than startup exceptions.
- Keep `help` and `exit` available when the contact data file cannot be saved; neither command
  writes that file. Other successful commands still save data.
- Repair a broken Javadoc class link and add Javadoc generation to Java CI. Refresh the
  release version, guides, screenshots, transfer instructions and release verification record.

## Download and run

Download `larperboard.jar` and `SHA256SUMS` from the
[v1.4.1 release](https://github.com/AY2627S1-CS2103T-W12-2/tp/releases/tag/v1.4.1).
Use Java 25 with JavaFX as prescribed in the [User Guide](../UserGuide.html#quick-start).
Put the JAR in a writable folder, open a terminal there, and run:

```text
java -jar larperboard.jar
```

On macOS, verify the download with `shasum -a 256 -c SHA256SUMS`; on Linux use
`sha256sum -c SHA256SUMS`. Both checksum files and the JAR must be in the same folder.
On Windows PowerShell, use `Get-FileHash .\larperboard.jar -Algorithm SHA256` and compare
its value with `SHA256SUMS`.

## Upgrade and data safety

Close the previous version. Back up `data/addressbook.json`, `preferences.json`, and the
JAR-folder `photos/`, then replace the JAR. Existing optional fields and old JSON continue to
load. JSON/preferences use the working folder, while photos use the folder containing the JAR;
launching from beside the JAR keeps these together. Keep the managed images when transferring
contacts to another computer.

Accepted PNG/JPEG imports remain limited to 5 MiB and 4096×4096 pixels. Absolute paths,
parent traversal and escaping symlinks are rejected. JSON stores relative photo references.
Imported assets are retained after replacement, clearing or deletion because session undo/redo
may restore them; unused files can remain. Unavailable images show a placeholder and warning.

Malformed contact data starts the app with an empty list and a warning. `help` and `exit`
preserve the unreadable file, but another successful command, including `list`, can overwrite
it. Restore or correct your backup before running further commands. Undo/redo and command
recall remain session-only and are cleared on restart.

## Known limitations

Only `sort added`, `sort edited` and `sort viewed` are public sort commands. `due` sets a
due-date order; `sort due`, `sort name` and `sort starred` are unavailable. Separate search,
group and filter commands replace the prior filter; combined filters remain deferred under #128.

Meeting event/role length still counts UTF-16 code units, and a truncated event preview can
split a surrogate pair. The pending [#181](https://github.com/AY2627S1-CS2103T-W12-2/tp/pull/181)
fix is excluded. `find` uses `person(s)` in its result text while other commands use `contact(s)`.
The UG lists the existing multi-screen and minimized Help window workarounds.

The [release verification record](../validation/v1.4.1.html) distinguishes successful checks
from the native desktop-control timeout and the simulated 150% layout check. This patch release
does not replace the separate v1.5 freeze/release checks tracked in #125.
