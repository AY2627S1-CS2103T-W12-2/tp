## Changes since v1.3

- Add private contact notes with `note INDEX nt/TEXT` and remove them with `note INDEX clear`.
- Star important contacts with `star` / `unstar` and show starred contacts with `filter starred`.
- Set follow-up dates with `followup INDEX d/YYYY-MM-DD`; `due` shows contacts due today or earlier in Singapore time.
- Record event names, meeting dates, and roles with `meeting`; clear individual fields or all context.
- Attach, replace, or clear one PNG/JPEG photo per contact with `photo`. Sources must be in the JAR folder; accepted images are copied into `photos/`. Limits are 5 MiB and 4096×4096 pixels. Imported files remain available for undo/redo.
- Search names, tags, notes, and event names using `find n/TERM t/TERM nt/TERM ev/TERM`. Repeated terms within one field use OR; different fields use AND. Plain name search remains available.
- Group contacts by tag and sort visible contacts by added, edited, or viewed time. Activity times persist in editable JSON and display in Singapore time.
- Undo and redo up to 50 saved contact changes in the current session, including notes, stars, follow-up dates, meeting context, and photo references.
- Recall the latest 50 submitted commands with Up/Down in the command field, including failed commands, with draft restoration and consecutive duplicate suppression.
- Enable assertions for Gradle runs and tests, and strengthen persistence, photo handling, and integration tests.

## Deferred work

The team agreed to release v1.4 without [#128](https://github.com/AY2627S1-CS2103T-W12-2/tp/issues/128).
Separate `find`, `group`, and `filter` commands replace the previous filter rather than combining.
Only `sort added`, `sort edited`, and `sort viewed` are supported; `sort name` and `sort starred` are unavailable.
Typed criteria within a single `find` command still combine as described above.

## Running the release

Download `larperboard.jar` from the [v1.4 release](https://github.com/AY2627S1-CS2103T-W12-2/tp/releases/tag/v1.4).
Use Java 25 with JavaFX as prescribed in the [User Guide](../UserGuide.html#quick-start).
Place the JAR in a writable folder, open a terminal there, and run:

```text
java -jar larperboard.jar
```

Back up `data/addressbook.json`, `preferences.json`, and `photos/` before upgrading or editing JSON.
Older contacts without the new optional fields continue to load. Keep `photos/` when transferring contacts.
Undo/redo and command recall are session-only and are cleared when the app closes.

See the [User Guide](../UserGuide.html) for commands, validation errors, and photo-folder instructions,
and the [Developer Guide](../DeveloperGuide.html) for implementation details.
